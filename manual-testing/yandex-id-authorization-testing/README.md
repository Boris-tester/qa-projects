# Yandex ID Authorization Testing

Ручное тестирование авторизации в Яндекс ID.

## Что протестировано

- авторизация по логину и паролю;
- авторизация по адресу электронной почты;
- авторизация по номеру телефона и SMS-коду;
- позитивные и негативные сценарии;
- валидация полей формы авторизации.
